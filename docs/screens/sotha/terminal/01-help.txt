$ sotha help
Sotha 0.1.0: the optional Pharos helper, reached only over Tor.

usage:
  sotha init   [-c config.yaml]           make the master key and data folder
  sotha check  [-c config.yaml]           key permissions, disk encryption, config
  sotha serve  [-c config.yaml]           serve on an onion service
  sotha serve  --tcp 127.0.0.1:PORT       …on loopback TCP instead (tests, development)
  sotha status [-c config.yaml]           row counts and the onion address
  sotha backup [-c config.yaml] OUT       a consistent copy of the database
  sotha code   [-c config.yaml] [--png F] its code for Enigma, as text and a QR (and a PNG)
